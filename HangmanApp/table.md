| **РАЗДЕЛ 1: ГЛАВНЫЙ ЭКРАН (Меню)** | | |
| **[Frontend] Верхняя панель и заголовок.**<br>Расположение иконки настроек в правом верхнем углу. По центру — логотип (иконка черепа) и текстовый заголовок «ВИСЕЛИЦА». |  |  |
| **[Frontend] Блок «Топ-3».**<br>Визуальная карточка с заголовком и списком из 3 элементов. Каждый элемент содержит название слова, счетчик побед и дату. Список имеет скролл. При отсутствии данных выводится серая заглушка. |  |  |
| **[Frontend] Кнопки управления.**<br>Крупная CTA-кнопка «СТАРТ» с закругленными краями. Кнопка справки «Как играть?» с иконкой вопроса. Модальное окно с правилами и кнопкой закрытия. |  |  |
| **[Backend] Подгрузка статистики.**<br>При открытии экрана происходит чтение сохраненных данных о текущей серии побед и топ-3 лучших результатов из локальной памяти. Сортировка топа по убыванию. |  |  |
| **[Backend] Навигация и состояния.**<br>Обработка нажатия на кнопку «СТАРТ» для перехода на игровой экран. Управление видимостью модального окна с правилами (открытие/закрытие). |  |  |
| **РАЗДЕЛ 2: ИГРОВОЙ ЭКРАН (Экран \game)** | | |
| **[Frontend] Игровое поле (Виселица).**<br>Статичные линии (столб, перекладина, веревка). Поэтапная отрисовка человечка с помощью анимации масштабирования. Наложение элементов кастомизации (цвет, шляпа, эмоции) на голову. |  |  |
| **[Frontend] Экранная клавиатура и слово.**<br>Сетка кнопок с буквами. Визуальное изменение цвета кнопок (зеленый при верном ответе, красный при ошибке). Отображение загаданного слова в виде прочерков. |  |  |
| **[Frontend] Модальное окно результата.**<br>Отображение окна при победе/поражении с иконкой статуса, текстом результата и кнопками «Далее» и «В меню». |  |  |
| **[Backend] Игровая логика.**<br>Генерация случайного слова (из API или локального массива). Обработка нажатий: проверка наличия буквы, открытие угаданных букв, инкремент счетчика ошибок (максимум 6). Проверка условий победы (все буквы открыты) и поражения (6 ошибок). |  |  |
| **[Backend] Сохранение прогресса.**<br>Сохранение текущего состояния (слово, угаданные буквы, ошибки) в память при выходе из игры. Обновление серии побед при выигрыше (сброс при проигрыше) и сохранение нового топа. |  |  |

| **[Backend] Управление глобальным состоянием.**<br>Считывание текущих настроек при запуске приложения. Обработка кликов по карточкам для смены темы, цвета, шляпы или эмоции. Мгновенное применение изменений ко всем экранам. |  |  |
