| **РАЗДЕЛ 1: ЭКРАН ВЫБОРА УРОВНЯ СЛОЖНОСТИ (по длине слова и лексическому уровню)** | | |
| **[Backend] Классификация слов по длине.**<br>Слова распределяются по категориям на основе количества букв:<br>• **micro** — длина слова ≤ 4;<br>• **short** — длина слова от 5 до 7;<br>• **medium** — длина слова от 8 до 10;<br>• **long** — длина слова ≥ 11. | | |
| **[Backend] Классификация слов по лексическому уровню (CEFR).**<br>Слова распределяются по уровням языковой сложности:<br>• **Лёгкий (A1–A2)** — простые повседневные слова;<br>• **Средний (B1–B2)** — более сложные и абстрактные понятия;<br>• **Сложный (C1–C2)** — редкие, специализированные термины. | | |
| **[Frontend] Индикатор сложности на главном экране.**<br>Иконка черепа выполняет роль кнопки и индикатора текущего уровня сложности. Спрайт иконки динамически меняется в зависимости от выбранного уровня: Сложный — череп демона, Средний — череп человека, Лёгкий — череп младенца с соской. | | |
| **[Frontend] Панель выбора уровня сложности.**<br>На экране отображаются 3 кнопки выбора уровня. При выборе соответствующей кнопки применяются модификаторы, привязанные к данному уровню сложности. | | |
| **[Frontend] Интерфейс переключения сложности (trap-door анимация).**<br>При нажатии на иконку черепа игровой экран плавно уезжает вверх (slide-up), открывая панель с 4 кнопками сложности. Выбор кнопки сложности открывает модальное окно с набором модификаторов для выбранного уровня (предыдущие модификаторы при этом сбрасываются). После подтверждения выбора все открытые окна закрываются, а игровой экран возвращается в исходное положение (slide-down). | | |
| **[Backend] Управление состоянием сложности.**<br>Хранение текущего уровня сложности и активных модификаторов в локальном хранилище. При смене уровня: сброс предыдущих модификаторов, применение новых, сохранение выбранного значения для восстановления после перезапуска приложения. | | |
| **РАЗДЕЛ 2: ПОДСКАЗКИ** | | |
| **[Frontend] Индикатор подсказок в HUD.**<br>В верхней части игрового экрана (рядом со счётчиком ошибок) отображается иконка лампочки/вопроса с числовым счётчиком доступных подсказок (например, 💡 × 3). При 0 подсказок иконка становится полупрозрачной/серой. Анимация появления при получении новой подсказки (пульсация + частицы). | | |
| **[Frontend] Кнопка «Использовать подсказку».**<br>Активная кнопка в нижней панели игрового экрана. Доступна только при наличии ≥1 подсказки и пока игра не завершена. При нажатии открывается мини-меню выбора типа подсказки (если типов несколько) либо сразу применяется эффект. Кнопка блокируется сразу после использования до следующего хода. | | |
| **[Frontend] Визуализация эффекта подсказки.**<br>При активации: выбранная буква подсвечивается золотым/неоновым цветом на 1.5 сек, затем переходит в обычный «открытый» стиль. Если подсказка исключает неверные буквы — они помечаются красным крестиком на клавиатуре с анимацией «зачёркивания». Звуковой эффект (мягкий «дзынь») и короткая вибрация (на мобильных). | | |
| **[Frontend] Модальное окно «Получена подсказка!».**<br>Появляется сразу после победы, если серия побед достигла порога. Показывает иконку награды, текст «+1 подсказка» и кнопку «OK». Окно не блокирует переход к следующему раунду — закрывается автоматически через 2 сек или по тапу. | | |
| **[Backend] Начисление подсказок за серию побед.**<br>Порог получения: каждая 3-я победа в серии (3, 6, 9, 12...). Формула: `hints += floor(currentStreak / 3) - floor((currentStreak - 1) / 3)`. При сбросе серии (проигрыш) счётчик серии обнуляется, но накопленные подсказки сохраняются. Максимальный лимит подсказок — 5 (защита от фарма). | | |
| **[Backend] Хранение состояния подсказок.**<br>Количество доступных подсказок сохраняется в локальное хранилище (localStorage / AsyncStorage) в объекте `{ hints: number, lastStreakReward: number }`. Ключ `lastStreakReward` нужен, чтобы не начислить награду дважды за одну и ту же серию при перезапуске приложения. | | |
| **[Backend] Типы подсказок и их логика.**<br>Реализованы 3 типа (выбор случайного при использовании):<br>1. «Открыть букву» — открывает одну случайную закрытую букву слова. Не тратит попытку.<br>2. «Исключить 3 буквы» — помечает 3 буквы, которых точно нет в слове, как неверные (красный крест на клавиатуре).<br>3. «Показать первую/последнюю» — открывает первую или последнюю букву слова (выбор по чётности/нечётности длины).<br>Тип выбирается случайно из доступных, чтобы игрок не мог фармить нужный. | | |
| **[Backend] Ограничения использования.**<br>Подсказку нельзя использовать: (1) если все буквы уже открыты (победа очевидна), (2) если ошибок = 6 (игра уже проиграна), (3) более 1 раза за один ход (защита от спама). После использования подсказки счётчик ошибок не увеличивается. | | |
| **[Backend] Интеграция с уровнями сложности.**<br>Модификатор сложности влияет на подсказки:<br>• Лёгкий (micro/short/A1-A2): порог получения — каждые 2 победы, макс. 7 подсказок.<br>• Средний (medium/B1-B2): порог — каждые 3 победы, макс. 5 подсказок (стандарт).<br>• Сложный (long/C1-C2): порог — каждые 5 побед, макс. 3 подсказки. На сложном уровне подсказка «Исключить 3 буквы» заменяется на «Исключить 1 букву» (баланс). | | |
